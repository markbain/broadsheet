== Description ==

A poster-on-a-wall block theme. Flat ink on paper, a visible hairline grid,
extreme contrast between display and body type, and deliberate empty stretches
used as punctuation. Three signature moves carry the identity: the slip, the
bracket, and one ink per band.

== Requirements ==

WordPress 6.6 or later. The theme uses theme.json version 3, the
`defaultSpacingSizes` setting (6.6), and `wp:pattern` inside template parts
(6.3). The masthead uses the CSS `:has()` selector, supported in all current
browsers.
